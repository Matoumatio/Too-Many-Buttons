# Too Many Buttons

### Description

- Too Many Buttons (TMB) est un jeu vidéo d’aventure à but "lucratif" hébergé localement ou sur le web
- A partir de la page principale, les utilisateurs pourront accéder à de nombreuses autres pages
- Le jeu mets en avant la culture internet et le fait de se perdre dessus à l'aide de diverses pop-ups et memes (médias ammusant viraux)
- Le développement de celui-ci est basé en grande partie sur l’aspect humoristique
- Contrairement au concept connu "Don’t press the button" avec un seul bouton au centre, ici l’interface est remplie uniquement de boutons et le but sera de ne pas se perdre (la majorité des éléments de l’interface seront cliquables)

### Contexte et Objectifs

- Divertissement, Culture Internet
- Objectif Général : Développer un jeux vidéo et le placer sur un serveur local ou sur internet (probablement Neocities)
- Public Cible / Utilisateurs : Amateurs de jeux vidéos et explorateurs du web

### Fonctionnalités Attendues

- Accéder au site
- Appuyer sur un bouton
- Appuyer sur une pub
- Naviguer entre plusieurs site à l'aide d'hyperliens
